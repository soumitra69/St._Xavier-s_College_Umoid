# St. Xavier's College Umoid - Official Website

A modern, responsive website for St. Xavier's College Umoid, a Jesuit institution in Meghalaya fostering knowledge, values, and community spirit.

## 🌟 Overview

This is the official website for St. Xavier's College Umoid, located in South West Khasi Hills, Meghalaya, India. The website serves as the primary digital platform for prospective students, current students, alumni, and the broader community to access information about the institution.

## ✨ Features

### Core Sections
- **Home Page**: Dynamic landing page with admission announcements and key highlights
- **About**: Information about the Jesuit institution and its values
- **Academics**: Details on various academic programs and courses
- **Admissions**: Application forms, prospectus downloads, and admission guidelines
- **Campus Life**: Student services, facilities, and campus activities
- **News & Events**: Latest updates, announcements, and event coverage

### Key Functionalities
- 📱 **Responsive Design**: Fully optimized for desktop, tablet, and mobile devices
- 🎓 **Student Portal**: Login system for current students
- 📚 **Digital Library**: Access to digital resources and research papers
- 🏢 **Placement Cell**: Information about career opportunities and recruitment
- 🏆 **Achievements Showcase**: Highlighting institutional rankings and recognitions
- 💬 **Student Testimonials**: Real experiences from current and former students
- 📰 **News Feed**: Regular updates on campus activities and achievements
- 📞 **Contact Integration**: Direct call and WhatsApp functionality
- 🤖 **Chatbot Support**: Instant assistance for visitor queries

## 🚀 Getting Started

### Prerequisites
- A modern web browser (Chrome, Firefox, Safari, Edge)
- Basic understanding of HTML/CSS/JS (for development)

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/soumitra69/St._Xavier-s_College_Umoid.git
   ```

2. **Navigate to the project directory**
   ```bash
   cd St._Xavier-s_College_Umoid
   ```

3. **Open the website**
   - Simply open `index.html` in your web browser
   - Or use a local server:
     ```bash
     # Using Python 3
     python -m http.server 8000
     
     # Using Node.js (http-server)
     npx http-server
     ```

4. **View the website**
   - Open your browser and go to `http://localhost:8000`
